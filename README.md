# محطة أنثى | Female Station

واجهة عربية متجاوبة لموقع **محطة أنثى** في النجف، مبنية كتجربة تعريفية راقية تعرض مفهوم المركز النسائي المتكامل: العناية والجلدية، السبا والصالون، الجيم النسائي، النسائية والتجميل، المختبر والصيدلية، وخدمات الليزر والحقن.

## فكرة التصميم

يعتمد الموقع اتجاه **«طقوس العناية الهادئة»**: لغة بصرية تحريرية دافئة تجمع الوردي الطيني والعاجي والنبيذي، مع مسار بصري متصل يعرض الأقسام بوصفها «محطات» ضمن رحلة الزائرة، لا كبطاقات خدمات منفصلة.

## التقنيات

| المجال | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript |
| التنسيق | Tailwind CSS 4 |
| التنقل | Wouter |
| الأيقونات | Lucide React |
| البناء | Vite |

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

لإنشاء نسخة إنتاجية والتحقق من الأنواع:

```bash
pnpm check
pnpm build
```

## ملاحظات المحتوى

الموقع واجهة تعريفية ثابتة ولا يحتوي قاعدة بيانات أو نظام حجوزات. روابط الاتصال والحسابات موجهة إلى بيانات محطة أنثى العامة، بينما يستخدم المحتوى الطبي لغة تعريفية عامة ولا يقدم تشخيصاً أو وعوداً بنتائج.

## الملفات الرئيسية

| المسار | الاستخدام |
|---|---|
| `client/src/pages/Home.tsx` | واجهة الصفحة الرئيسية والمحتوى |
| `client/src/index.css` | نظام الألوان والحركة والأنماط الخاصة |
| `ideas.md` | فلسفة التصميم وقرارات الأسلوب |

## النشر

يمكن نشر المشروع كواجهة ثابتة عبر أي استضافة تدعم تطبيقات Vite. لا تحفظ أي مفاتيح أو بيانات سرية في المستودع.
